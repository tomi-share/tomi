Vue d’ensemble

    Ce que le relais voit, et ce qu’il ne voit pas

    Le relais est aveugle : il stocke et fait suivre des octets chiffrés sur les appareils, sans aucune clé. Ni contenu, ni titre, ni nom de fichier, ni secret.

    Ce panneau montre ce qu’il sait déjà : comptes, tailles, dates, identifiants courts, nom de chaque appareil. « Éléments » compte des enveloppes chiffrées.

    Retirer, supprimer, vider la corbeille ou inviter demande ta clé d’accès à chaque fois : une session volée ne le peut pas. Les clés et l’adresse du panneau ne se changent que sur le serveur.

          Activité du panneau 0

          Les actions sensibles (retraits, suppressions, corbeille, invitations, refus) sont gardées 90 jours, avec l’identifiant court de la cible et le numéro de la clé. Le reste est en mémoire jusqu’au redémarrage.

          Jamais de nom d’appareil, de jeton, de code, d’adresse ni de contenu.

          Rien à signaler depuis le démarrage du relais.

            Quota par défaut d’un espace

            Plafond de chaque espace sans quota propre. Sans réglage ici ni max_space_bytes, aucune limite.

            Effet immédiat, rien n’est supprimé : un espace au-dessus ne peut plus que libérer de la place (le panneau te prévient avant).

            Mio

            Accès au panneau

            Une clé liée à l’appareil ne quitte pas son support : sûre même si ton compte iCloud, Google ou ton gestionnaire de mots de passe est pris. Une clé synchronisée suit ce compte.

            Garde-en deux pour ne pas dépendre du serveur si tu en perds une.

            Clés d’accès

              Clé exigée pour supprimer ou vider
              Autres sessions ouvertes

              Sur le serveur seulement

              • Ajouter ou retirer une clé. Sinon, une clé volée pourrait s’en ajouter une autre.
              • Exiger la clé liée à l’appareil pour supprimer ou vider : une session ne doit pas baisser la garde.
              • Changer l’adresse du panneau : tu pourrais t’enfermer dehors. En urgence, « Fermer toutes les sessions ».
              • Réinitialiser l’accès, si tu as perdu toutes tes clés.
              Équivalent en ligne de commande
              • Lister les clés
                tomi-relay admin web keys
              • Retirer une clé (jamais la dernière)
                tomi-relay admin web keys remove N
              • Ajouter une clé (code valable 15 min)
                tomi-relay admin web enroll
              • Exiger la clé liée à l’appareil pour supprimer
                tomi-relay admin web policy --space-deletion device-key
              • Changer l’adresse (ferme toutes les sessions)
                tomi-relay admin web --rotate-path
              • Tout réinitialiser (clés et sessions)
                tomi-relay admin web reset

              Diagnostic

              À joindre pour signaler un problème : ni identifiant d’espace, ni nom d’appareil, ni jeton.
